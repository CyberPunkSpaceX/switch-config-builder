SSH keys recommended

With a key, nobody types a switch password. The server makes each key; the private half never leaves the server and is stored encrypted. There are two, each for its own account on the switches:

  • Read-only key: fetching configs, compare, nightly backups and discovery. Every member of {{ c['name'] }} can fetch with it, Read-only members too (they can't type a switch password instead).
  • Config key: pushing approved configs. Only admins of {{ c['name'] }} can push, and a push with a key always signs in with this one, never with the read-only key.
